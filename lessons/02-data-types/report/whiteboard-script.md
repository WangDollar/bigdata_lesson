## 讲稿

### 第一，一行代表谁

我们这次拿到的是四个中心的心脏病记录，表面上看是九百二十条。但我现在意识到，这九百二十条记录并不等于九百二十个独立患者。记录编号只是教学编号，是中心名加上文件里的行号，不是患者标识符。而且有两条记录的临床字段完全一样，我没办法判断这是同一个人录了两次，还是两个人的数值恰好相同。

所以我现在拿到数据，会先问「一行代表谁」，而不是直接进入分析。这是我觉得拿到科研数据最先该有的一个思考。

### 第二，数字不等于数量

第二个我觉得很重要的学习，是数字不等于数量。

年龄 63 确实是一个数量，可以求平均，也可以标准化。但胸痛类型 1、2、3、4 只是类别编号，不能说 4 是 2 的两倍，也不能把它当成连续变量去算均值。如果把 1、2、3、4 改成 10、20、40、80，每个人属于哪一类一点没变，均值却完全变了，说明这个均值本来就没有意义。

同样的道理，y 是由 num 生成的：num 大于 0 就记为 1。如果再拿 num 去预测 y，其实是把答案泄漏给了模型。

所以我现在的理解是：先理解变量，再选方法，而不是反过来。

### 第三，异常不等于错误

遇到 0 值、缺失值、极端值的时候，我以前可能会觉得「看着不对就删」。但这次我明白了，异常不等于错误。

比如 Switzerland 中心，胆固醇有 123 个 0，也就是这个中心的全部记录。胆固醇是 0 在生理上不可能，所以它肯定不是真实的测量结果；但它是录入错了，还是「没测」被填成了 0，我判断不了。反过来，胆固醇 603 这样的极端值，可能是录错了，也可能真的是一个特殊的病人。

一个是不可能的值，一个是可能的值，但在没有原始记录、复测或编码说明之前，这两个我都不能凭感觉处理。我只能把它们标记为待核实：保留原值，待核实期间不拿来算均值，而不是立刻修改或者删除。

数据处理必须有证据，这是我觉得自己以后做科研最应该记住的一点。

### 第四，删数据会改变研究对象

删数据不是纯技术操作，它会改变研究对象。

如果只保留 13 个特征全都不缺失的完整记录，最后只剩 299 条，其中 297 条来自 Cleveland，Switzerland 一条都不剩。Cleveland 原来只占三分之一，删完占到 99%。研究对象就从四中心变成了几乎单中心，这已经不是原来那个问题了。而且整个过程里，没有任何一行代码是写错的。

所以我现在会先问：删完之后，我们研究的还是同一群人吗？这也是为什么我在作业里从最开始的方案 B 改成了方案 C：不删行，而是限制字段。

> 最后一句（B→C）用来对上提交的追踪表第 0 行；不需要可删，不影响主线。

### 最后，数据的边界

最后我想补充一个边界意识：数据有它能回答的问题，也有它不能回答的问题。

这份表现在能做的，是分中心描述年龄、性别、胸痛这些字段，以及在胸痛类型和是否患病之间做有限的比较。

但它不能回答随访风险，因为没有随访时间和事件状态。同样，它也做不了单细胞或者影像研究，因为没有细胞×基因、图像×像素这样的矩阵，也没有能把细胞或图像连回同一个人的编号。

如果将来补充了统一的随访起点、观察时长和事件状态，就可以建立新的随访研究。补什么，就多出什么研究边界。

所以我最后的理解是：数据决定我们能说什么，也决定我们暂时不能说什么。

### 收尾

*〔指板书〕* 这就是我这次作业之后最想带走的科研习惯：先问对象，先问变量含义，先问证据，然后才是方法。谢谢。

## 扩展模块（只有你一人讲、时间还多时才用）

### A. 接在第三段后：这些 0 到底有多大影响（约 40 秒）

> 这些 0 如果不处理，会直接改掉结论。除了瑞士的 123 个，长滩医院还有 49 个，一共 172 个。把它们当真实值算进去，胆固醇的均值是 199，反而比中位数 223 还低——正常的生理指标不该出现这种反向差，就是这些 0 拉下来的。

### B. 接在第三段后：缺失本身可能带信息（约 40 秒）

> 缺失也不只是「少了几个数」。显影血管数这一列，全表只有 309 条有值，匈牙利 294 条里只有 3 条。这更像是「这个人有没有被送去做造影」，而不是随机漏记。如果是这样，这一列缺不缺，本身就和是否患病有关，拿它做预测变量是危险的。

### C. 接在第二段后：同一个「均值」的三种含义（约 40 秒）

> 同样是求均值，在这张表里有三种完全不同的意思：年龄的均值 53.5 是真的数量中心；胸痛编号的均值没有意义；而 y 这个 0/1 变量的均值，等于阳性的比例。同一个运算，三种解读，所以必须先定变量类型再选方法。

### D. 接在边界段：有限比较的例子（约 1 分钟）

> 比如胸痛和是否患病：胸痛类型 4（无症状）那一类，患病 392 条、未患病 104 条；类型 1（典型心绞痛）是 20 比 26，方向反过来了。所以胸痛值得作为预测变量，但要用指示变量编码，不能按 1234 当数量。之所以说是「有限」比较，是因为两件事还没核实：记录之间是否独立；各中心阳性比例差别很大，合在一起比会混进中心差异。

## 被追问时的一句话应答（记方向，不用逐字背）

| 追问 | 回答 |
|---|---|
| 胆固醇 0 怎么可能不算错？ | 它肯定不是真实测量，这点我同意。我不确定的是成因：录入错误还是「没测」填成 0。成因不同处理不同——录错可以回查原始记录改正，没测只能当缺失。所以先标记待核实。 |
| 标记待核实，那均值怎么算？ | 待核实期间这一列不进均值计算。如果把 0 算进去，均值是 199，比中位数 223 还低，就是瑞士 123 个加长滩 49 个、一共 172 个 0 拉下来的。 |
| 603 为什么不删？ | 异常可能是错误、真实极端值或特殊人群。这条没有复测记录，删掉就是凭感觉。 |
| 你说有限比较，有限在哪？ | 两点：记录之间是否独立没核实（有 2 条完全重复、没有身份表）；各中心阳性比例差很大（瑞士 93.5%、匈牙利 36.1%），合起来比会混进中心差异。 |
| 标准化能解决中心差异吗？ | 不能。标准化只改数值尺度，不改含义、不修缺失、不修来源偏差。要估泛化性能，还得先划分数据，只用训练部分算均值和标准差。 |
| 中心差异就是批次效应吗？ | 不是。阳性比例差可能来自患者构成和转诊。判定批次效应要同一个标准样本在不同仪器上的重复测量证据，这张表没有。 |
| 高维是一种变量类型吗？ | 不是。两万个基因是「一行一细胞、一列一基因」的矩阵结构问题，不是某一列的测量尺度。 |
| 为什么不选 D 暂缓？ | Cleveland 完整度 98%，字段也有官方字典支持，有一部分是有依据的。直接暂缓等于浪费可用的部分，我的做法是限制范围加停止条件。 |
| 为什么不选 B 修订后合并？ | 修订解决不了「删完只剩 Cleveland」，也修不出没测过的胆固醇。修编码修不出没测过的数据。 |

## 卡住怎么救（背下这三句）

1. **忘了数字**：看板书，关键数字都在板上。实在想不起就说量级：「瑞士那一列全部是 0」「删完几乎只剩 Cleveland」。说量级和方向，比说错一个精确数字好。
2. **忘了下一段**：看板书下一个问题，直接说「下一个我会问的是……」，把问题念出来就接上了。
3. **被问住了**：「这一条我当前不可判定，我需要的是〈原始记录／复测／编码说明／身份链接表〉。」工作单 Q4 明确要求对没有直接证据的问题写「当前不可判定」，这是得分点，不是失分点。
