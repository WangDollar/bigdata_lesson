# 学生作答与复算文件

这份作答使用工作单和配套 CSV 独立完成，没有读取教师参考或 `review/` 数值答案。

- `统计检验与假设设计.docx`：交上去的完整答卷。
- `学生作答.md`：同一答卷的文本版本。
- `analysis-plan.md`：此次计算前固定的分析约定，不是正式预注册。
- `src/homework/analyze.py`：实际数据分析脚本，输入为 `data/heart-disease-hypothesis.csv`。
- `outputs/homework/results.json`：全精度结果、输入文件 SHA-256 和软件版本。
- `outputs/homework/` 下的 `group-summary.csv`、`missingness-by-site.csv`、`missingness-by-site-and-disease.csv`：描述统计和纳入情况。
- `site-sensitivity.csv`、`adjusted-model.csv`：分中心结果和 HC3 稳健调整模型。
- `field-audit.csv`：数值字段的计数与范围。
- `thalach-distribution.png`：两组 thalach 分布图，插入答卷图 1。
- `src/homework/build_answer.py`：根据结果生成答卷的排版脚本（输出 `统计检验与假设设计_学生完成版.docx`）。

复算需要 Python 3.12、NumPy、pandas、SciPy、statsmodels、matplotlib；重建 Word 另需 python-docx。
答卷中文字体为等线（DengXian），Windows 10 及以上和 Office for Mac 均自带，跨平台打开时分页一致。
本次运行版本写在 `results.json`。在已安装依赖的环境中运行：

```bash
python src/homework/analyze.py      # 在 lessons/05-hypothesis-testing 下运行
python src/homework/build_answer.py
```

分析脚本保留了手工 Welch 公式与 SciPy 结果的数值一致性校验。它不修改源数据。
均值差统一定义为 disease=1 减 disease=0；模型区间采用 t 分布而非默认正态近似。
源数据为观察性跨中心资料；分层比较是探索性敏感性分析，未用来选择性改变主要假设。
看过第一版结果后补充的分析列在 `analysis-plan.md` 的“事后补充”一节。
