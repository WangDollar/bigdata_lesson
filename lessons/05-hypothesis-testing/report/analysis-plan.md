# 学生作答分析约定

本约定在本次读取分组心率结果和运行检验前写下，用于固定这次练习的方法；它不是研究实施前的正式预注册。

- 数据：`../data/heart-disease-hypothesis.csv`；不读取教师参考或 review 中的数值答案。
- 分组：`disease=1`（`num>0`）与 `disease=0`（`num=0`）。
- 主要终点：`thalach`，单位次/分。
- 主要效应：疾病组均值减无疾病证据组均值；H0 为该差等于 0，H1 为不等于 0。
- 主要检验：双侧 Welch 独立样本 t 检验，α=0.05；报告均值差、Welch 95% CI 和精确 p 值。标准化效应仅作补充。
- 纳入规则：主要分析只排除 disease 或 thalach 缺失的记录；不因其他字段缺失而整行删除，不事后剔除极端值，不填补主要终点。
- 核对分组编码、样本流失、重复记录编号和数值范围；分别按疾病组和中心报告缺失情况。
- 敏感性分析：按 site 分层的均值差；线性模型 thalach ~ disease + age + sex + C(site)，使用 HC3 异方差稳健标准误和 t 区间；Mann–Whitney U 检验作为分布差异的补充，不将其当成均值检验。
- 不运行数据中不存在的前后配对分析；任务 3 其余条目是方法选择题，不将全部条目扩展为新的主要假设。
- 结论限于观察性资料的关联；讨论中心、年龄、性别、缺失选择和未测量因素。

## 事后补充（看过第一版结果后加入）

以下分析在主要检验完成后才加入，用于描述缺失和检查稳健性，不改变主要终点、H0/H1 或主要结论，答卷中均标为事后或探索性：

- 比较 thalach 缺失者与纳入者的年龄、性别和疾病比例，并检查同一记录中其他检查字段是否同时缺失；
- 排除缺失集中的 VA Long Beach 后重做 Welch 比较；
- `disease × C(site)` 交互项的 HC3 联合检验，用于描述中心间异质性；
