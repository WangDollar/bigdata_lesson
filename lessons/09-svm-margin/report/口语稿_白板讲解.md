# 开场（约 40 秒）

大家好。我想从老师留的那道原题讲起：为什么 SVM 不是简单地找一条刚好把两类分开的线？做作业之前我觉得这个问题有点多余，线分开了不就行了吗。做完之后我的回答是：刚好分开的线有无数条，SVM 要的是最安全的那条；而真实数据根本分不开，这时候它干的事是给违例定价。下面我按自己做实验的顺序讲一遍这两句话是怎么来的。做之前我看了几个讲 SVM 的视频和博客，有几个比方后面会借用。

【板书：左上角写下原题，讲完全程不擦】

# 一、三条线都对，凭什么选中间那条（约 1 分 50 秒）

数据是 UCI 的脊柱数据，310 个病人，每人两个测量：骨盆入射角和滑脱程度，标签是正常还是异常。老师先让我们从训练集里挑了 8 个能分开的点看几何。

【板书：画两团点，左下四个圆圈是 NO，右上四个三角是 AB，中间画三条平行线】

这三条线法向量一样，只是上下平移，8 个点全都分对，训练错误都是零。所以只看训练错误，选不出来。我运行之前的直觉是中间那条好，因为离两边都远。问题是“远”怎么量。

决策函数是 f 等于 w 转置 z 加 b。f 等于零是边界，符号给类别。但 f 本身不能直接当距离，因为把 w 和 b 同乘 3，边界不动，预测不动，f 却变成 3 倍。所以要除以 w 的长度。刘建平的博客把 f 叫函数间隔，除以 w 的长度之后叫几何间隔，同乘 3 就是函数间隔变了、几何间隔没变。

【板书：f = wᵀz + b；距离 = |f| / ‖w‖】

有了这个，三条线就能打分：每条线找离它最近的点，算几何间隔。中间那条是 0.957，另外两条都是 0.383。差出来的 0.574 正好是截距平移 0.6 除以 w 的长度，我手算核对过。

为什么看最近的点而不是所有点的距离之和？因为和会被远点撑大。margin 是一个最坏情况的量。SVM 把最近的点规范化到 y 乘 f 等于 1，那么 f 等于正负 1 两条线之间的宽度就是 2 除以 w 的长度，最大化这个宽度就是最小化 w 的长度。MIT 公开课里 Winston 教授管这个叫“最宽的街”，边界是中线，两条虚线是路肩；林轩田老师叫“胖的边界”，三条都分对的线里挑最胖的那条，因为它最经得起测量误差。

【板书：在中间那条线两侧画两条虚线，标 2/‖w‖；把压在虚线上的两个点圈出来】

# 二、边界是谁定的，分不开怎么办（约 1 分 45 秒）

圈出来的这两个点就是支持向量。我做了删点实验：删掉离边界最远的那个点，再拟合，边界变化是多少？我预测“很小”，结果是精确的零，小数点后六位全是零。因为非支持向量的对偶权重 α 就是零，它根本不在解里。删掉一个支持向量，边界就转了。

【板书：w = Σ αᵢ yᵢ zᵢ，在 α 下面写“非 SV 为 0”】

然后是分不开的情况。工作单让我们复制一个点，坐标不变，标签反过来。硬间隔要求这个坐标上 f 既大于等于 1 又小于等于负 1，同一个输入 f 只有一个值，无解。换核也救不了，因为核只是换特征表示，f 还是一个输入对应一个输出。

软间隔的办法是允许违例，但每次违例付代价，代价就是 hinge。

【板书：ℓ = max(0, 1 − y·f)，画折线：横轴 y·f，在 1 处拐到零】

我原来没分清的一点：y 乘 f 等于 0.4 的点分对了，hinge 却是 0.6。分对不等于没违例，林轩田的课件说得很直接：软间隔罚的是违例的量，不是错误的个数。李宏毅的比方我觉得特别好记：hinge 像期末考，所有科目及格就行，不追求某一科满分。y 乘 f 过了 1 就没有奖励，所以带外的点对 w 没有贡献，这和删 V072 变化为零是一回事。

我顺着这个数了 linear C 等于 1 在 186 条训练集上的解。林轩田把点分三类：α 等于零的非支持向量在带外，α 在 0 和 C 之间的“自由支持向量”压在带上，α 等于 C 的“有界支持向量”在带内或错误侧。我数出来是 97、3、86，正好对上。所以软间隔下支持向量不是“在间隔线上的点”，很多入门博客画的是硬间隔的图。

# 三、C 到底在调什么（约 1 分 15 秒）

【板书：min ½‖w‖² + C Σ hinge，在第一项下面写“带宽”，第二项下面写“违例”】

C 是这两项的相对权重。我只改 C，其他全固定，跑了五个值。预测对了一半：C 越大，hinge 单调下降，带宽单调变窄。但验证的平衡准确率不是单调的，C 等于 1 最高，0.76。

推翻我直觉的是 C 等于 0.01 这一行。它的带宽是 12，看起来间隔最大。但训练错误正好是 60，就是训练集里 NO 的总数，验证集上特异度是 0。它把所有人都判成异常。原因是违例几乎不要钱，优化器把 w 压到接近零，w 小等于带宽大，但 f 几乎成了常数。所以“间隔宽”这件事孤立看没有意义，必须和违例一起看。

【板书：写一个小表，三行：C=0.01 带宽 12 特异度 0；C=1 验证 0.76；C=100 训练错误最少但验证 0.71】

# 四、核、gamma 和单位（约 1 分 30 秒）【可跳】

核是某个特征空间里的内积。知乎上流传很广的那个“魔鬼与大侠”的比方大家可能看过：桌上两种颜色的球一根棍分不开，大侠一拍桌子，球飞到空中，用一张纸就分开了。拍桌子就是映射，纸是高维空间里的超平面。StatQuest 讲多项式核那一期补了另一半：核函数算的是高维空间里的点积，并不真的把高维坐标算出来。这就是工作单问的“二次核为什么不必显式升维”。

RBF 核是 exp 负 gamma 乘距离平方，gamma 越大，相似度随距离掉得越快，每个支持向量只影响身边一小块。距离 1 的时候，gamma 0.1 相似度 0.90，gamma 1 是 0.37。

我固定 C 看 gamma，再固定 gamma 看 C，两个结果出乎意料。gamma 等于 0.01 不是“边界很平滑”，是根本没有边界，全判 AB，因为所有点两两相似度都接近 1，核矩阵成了常数矩阵。另一头，C 等于 100、gamma 等于 10 的时候，训练 0.91，验证掉到 0.67，边界碎成好几块。林轩田的课件在软间隔那讲末尾专门写了一句警告：SVM 仍然会过拟合，高斯核要仔细选 gamma 和 C。这一行就是那句话的实例。

单位实验最干脆。把一个输入乘 100，信息没变。不标准化的话，验证分数最大差 1.5，186 个训练点全部变成支持向量。训练集上标准化之后，差是 10 的负 14 次方，就是浮点误差。RBF 建立在距离上，距离依赖单位，标准化把乘 100 正好抵消了。

# 五、验证、冻结、测试，和一个意外发现（约 1 分 15 秒）

按老师定的规则，两个家族各在验证集上选一组：linear C 等于 1，验证 0.76；RBF C 等于 10、gamma 等于 10，验证 0.80。记录完再开测试集。测试结果两个几乎一样，0.83 和 0.84，只差一个假阴性，AUC 的排序还反过来了。所以验证上那 0.04 的差距，在 62 条数据上不值得当真。

然后我去看错的是谁。假阴性有十一二个，滑脱程度全部在负 8 到 5 之间，和正常人完全重叠。我想起数据说明里说 AB 是两种病合并的，就去 UCI 下了三分类版本对上 ID。结果是：脊椎滑脱的病人，29 个全判对；椎间盘突出的病人，13 个只对了 1 到 2 个。

【板书：横轴写“滑脱程度”，画三团：NO 和 DH 都挤在 0 附近重叠，SL 在右边远处；边界竖在中间】

也就是说模型学到的是“滑脱程度大就是滑脱症”，对椎间盘突出基本是瞎的，换哪种核都一样。这也解释了 RBF 在验证集上多出来的优势为什么没保住：验证集里它碰巧包住了几个 DH，测试集里没有。

# 收尾（约 40 秒）

回到原题。SVM 不是找一条刚好分开的线，因为那样的线有无数条，而且最脆弱；它找的是给最近的点留最大余地的那条，分不开的时候用 C 和 hinge 把“多少违例换多宽的带”写进目标函数。

这次作业我学到的最硬的一条不是关于 SVM 的：它补不了特征里没有的信息。DH 这个局限换什么核、调什么参数都在，只能换特征。如果真要给研究组一个建议，我会倾向 linear，理由是测试表现一样、对输入扰动的敏感度只有 RBF 的一半、而且系数能解释。

最后说一句自己的位置。July 的《支持向量机通俗导论》把理解 SVM 分成三层：了解、深入、证明。我大概到了第一层半，间隔、支持向量、C 和核是自己算出来的；对偶和 KKT 只在 shuhuai008 的白板推导里看懂了结论，为什么非支持向量的 α 恰好是零，还得回去补。谢谢大家。

【板书：在原题下面写两行：① 无数条 → 最安全的一条　② 分不开 → 给违例定价】

# 老师可能的追问和答法

教案里列了老师准备的追问，加上我自己觉得会被问的，一共十一个。每个答两三句就够。

**为什么要除以权重长度？** 因为 (w, b) 同乘一个正数，边界和预测都不变，f 却跟着变。f 是函数间隔，依赖参数化；除以 ‖w‖ 之后是几何间隔，才是真正的距离，不同的线才能比。

**判对了为什么还有损失？** hinge 是 max(0, 1 − y·f)，y·f 在 0 和 1 之间时分对了但在带内，损失还是正的。SVM 罚的是“离边界不够远”，不只是“分错”。用李宏毅的话说，hinge 要求所有科目及格，0.4 分是没及格。

**支持向量能不能当特征？** 不能。支持向量是训练样本，是当前这组特征、这个 C、这些数据下几何上贴着边界的点，换一组特征就换一批。它既不是特征，也不是最典型的病人。

**很多博客说支持向量是“离超平面最近的点”，和老师的定义冲突吗？** 那是硬间隔的图景。软间隔下按老师的定义“对偶权重非零”，支持向量包括带上、带内和分错的点，我在 186 条训练集上数过，89 个支持向量只有 3 个真的在带上。博客的说法在软间隔下不准确。

**改变单位之后 gamma 还是同一种设置吗？** 名义上是同一个数，实际上不是。gamma 作用在距离平方上，一个输入乘 100，距离平方的这个分量乘一万，gamma 等于 0.1 对应的作用范围相对数据变得极小。标准化之后才是同一种设置。

**RBF 的虚线为什么不能用尺量出和线性一样含义的间隔？** RBF 的间隔在特征空间里，投回二维平面以后，f 等于正负 1 的等值线间距随位置变化，不是到边界的等距线。线性的 2/‖w‖ 是标准化平面上的真实宽度，两个不是同一种量。

**为什么线性 C 等于 0.01 最宽却最差？** 违例代价太低，优化器把 w 压到接近零，带宽是 2/‖w‖ 所以变得很大，但 f 几乎是常数，全判多数类。宽是用“不区分”换来的。

**高维少样本和大样本为什么是不同的问题？** 高 p 的问题是信号是否存在、尺度是否可比、验证集够不够稳。大 n 的问题是核矩阵 n 乘 n 算不算得动。一个是统计问题，一个是计算问题。

**测试完如果想换核，需要什么？** 需要新的保留数据。现在这 62 条已经看过了，再用它选核就变成第二个验证集。只能换核之后重新走验证流程，再找一批没碰过的数据。

**为什么倾向 linear 而不是验证分更高的 RBF？** 三个理由：测试上两个只差一个假阴性；扰动实验里 RBF 的翻转率是 linear 的两倍；linear 的系数能解释。但老师说不要选冠军，所以我只说倾向，不说结论。

**DH 的发现用了三分类标签，算不算偷看？** 三分类标签没有参与任何训练和选参，只在测试结束后用来解释错误是哪一类人，不会再改模型。工作单要求用混淆矩阵解释至少一种错误，这是在回答那个要求。
