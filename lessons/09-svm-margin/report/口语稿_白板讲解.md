# 开场

大家好。我想从老师留的那道原题讲起：为什么 SVM 不是简单地找一条刚好把两类分开的线？做作业前我觉得这题多余，分开了不就行了吗。做完以后我的回答是两句话。第一，刚好分开的线有无数条，SVM 要的是最安全的那条。第二，真实数据根本分不开，这时候它做的事是给违例定价。下面按我做实验的顺序，讲这两句话是怎么来的。

【板书：左上角写原题，全程不擦】

# 模块一　三条线都分对，选哪条

老师让我们从训练集里挑了 8 个能分开的点。

【板书：左下四个圆是正常，右上四个三角是异常，中间三条平行线】

这三条线方向一样，只是平移，8 个点全分对，训练错误都是零。所以只看训练错误，选不出来。

我的直觉是中间那条好，因为离两边都远。可是“远”怎么量？决策函数 f 等于 w 转置 z 加 b。f 本身不能当距离：把 w 和 b 同乘 3，线没动，f 却变成了 3 倍。所以要除以 w 的长度。刘建平的博客把 f 叫函数间隔，除完以后叫几何间隔。

【板书：f = wᵀz + b；距离 = |f| / ‖w‖】

每条线找离它最近的点算几何间隔：中间那条 0.96，另外两条都是 0.38。SVM 选的就是让最近的点最远的那条。MIT 的 Winston 教授管它叫“最宽的街”，林轩田老师叫“胖的边界”，意思一样：街越宽，越经得起测量误差。

【板书：中线两侧画两条虚线，标 2 / ‖w‖】

# 模块二　这条线是两个点定的

压在虚线上的两个点，V217 和 V061，就是支持向量。我做了删点实验：把离边界最远的那个点删掉重新拟合，边界变多少？我预测“变得很小”，结果是精确的零，小数点后六位全是零。

为什么是精确的零？我在这 8 个点上手算了一遍。PPT 上有个式子：w 等于 α 乘 y 乘 z 再求和。这里只有两个支持向量，所以 w 就是从 V217 指向 V061 的箭头乘一个系数，算出来是 0.546。

【板书：把两个圈出来的点连成箭头，写 w = 0.546 ×（z₊ − z₋）】

所以边界就是这两个点连线的垂直平分线，街宽 1.91 就是这两个点之间的距离。其他六个点的 α 是零，根本不在式子里，删掉当然没影响。那删掉 V061 呢？旁边的 V068 顶上来，街从 1.91 变宽到 2.20。少一个约束，街只会更宽。

# 模块三　分不开怎么办

真实数据是分不开的。工作单里有个极端例子：把一个点复制一份，坐标不变，标签反过来。硬间隔要求同一个位置上 f 既大于等于 1，又小于等于负 1，无解。换核也没用，同一个输入只能有一个输出。

软间隔的办法是允许违例，但要付代价，代价就是 hinge。

【板书：ℓ = max(0, 1 − y·f)，画折线，在 1 处拐平】

y 乘 f 等于 0.4 的点，分对了，hinge 还有 0.6。分对不等于没违例。李宏毅老师有个比方：hinge 像期末考，每科及格就行，不追求某一科考满分。过了 1 就没有奖励，所以带外的点对边界没有贡献，这和刚才 α 等于零是一回事。

# 模块四　C 实验

【板书：min ½‖w‖² + C Σ hinge，第一项下面写“街宽”，第二项下面写“违例”】

目标函数有两项，一项要街宽，一项罚违例，C 是违例的单价。这个实验只改 C，训练数据、scaler、验证集全部固定，跑了五个值。

我的预测是 C 越大，违例越贵，hinge 会降，街会变窄。这两条都对了，而且它们是能证明的：把两个 C 各自的最优性不等式加起来，街宽那一项消掉，就得到 hinge 只降不升。但验证表现没有这种保证，实际是先升后降，C 等于 1 最高，0.76。

推翻我直觉的是 C 等于 0.01。它的带宽是 12，看起来间隔最大。可是训练错误正好 60 个，就是训练集里正常人的总数，验证特异度是零。它把所有人都判成了异常。违例太便宜，优化器干脆把 w 压到接近零。街是宽了，f 却变成了常数。所以“间隔宽”单独看没有意义，要和违例放在一起看。

【板书：三行小表　C=0.01 街宽 12、特异度 0　C=1 验证 0.76　C=100 验证 0.71】

# 模块五　核、gamma 和单位

核是变换之后的内积。知乎上有个流传很广的比方：桌上两种颜色的球，一根棍分不开；大侠一拍桌子，球飞到空中，用一张纸就分开了。拍桌子是变换，纸是高维空间里的平面。课上用的二次核我展开验过，它等于把两个输入变成六个再做内积，两种算法结果都是 0.826。

SVM 为什么恰好能用核？把刚才的 w 代进去，f 里面数据只以内积的形式出现，把内积换成核就行了。

【板书：f(z) = Σ αᵢ yᵢ K(zᵢ, z) + b】

RBF 核按距离算相似度，gamma 管的是多远还算相似。这里我两头都猜错了。gamma 等于 0.01，我以为边界会很平滑，结果是没有边界，全判异常，因为所有点互相都很像。我后来验证过，它和一个 C 等于 0.02 的线性 SVM 预测完全一样，其实就是刚才 C 太小的那个毛病。另一头，gamma 等于 10 再配 C 等于 100，训练 0.91，验证掉到 0.67，边界碎成好几块。

单位实验最干脆。一个输入乘 100，信息没变。不标准化，分数最多差 1.5；标准化以后只差 10 的负 14 次方。RBF 靠距离，距离靠单位。

# 模块六　验证、错的是谁、测试

按规则在验证集上各选一组：linear 是 C 等于 1，验证 0.76；RBF 是 C 等于 10、gamma 等于 10，验证 0.80。

我去看线性模型错的是谁。漏掉的 16 个异常，滑脱程度都很小，和正常人混在一起。数据说明里写过，异常是两种病合并的。我去 UCI 找了三分类的版本对上编号：这 16 个里 15 个是椎间盘突出。

【板书：横轴“滑脱程度”，正常和椎间盘突出两团叠在 0 附近，脊椎滑脱一团在右边，边界竖在中间】

模型学到的其实是“滑脱程度大就是滑脱症”，对椎间盘突出基本是瞎的。RBF 在验证集上多对了 8 个，靠的是局部圈出来的几个小块。

【下面三句只在老师让打开测试集以后讲】打开测试集，两个模型是 0.83 和 0.84，只差一个病人。RBF 多对的那 8 个没保住，13 个椎间盘突出只对了 2 个。验证集上那 0.04 的优势，是 62 条数据里的运气。

# 收尾

回到原题。SVM 不是找一条刚好分开的线，因为那样的线有无数条，而且最脆弱。它找的是给最近的点留最大余地的那条；分不开的时候，用 C 和 hinge 把“多少违例换多宽的街”写进目标。

优势是目标清楚，边界只靠少数几个点，小数据就能用。局限是对单位和参数敏感，分数不是概率。但这次最硬的一条不是 SVM 的问题：它补不了特征里没有的信息。椎间盘突出换什么核都分不出来，只能换特征。

最后交代一下自己的位置。July 那篇《支持向量机通俗导论》说理解 SVM 有三层。间隔、支持向量、C 和核，我是自己算出来的。对偶我没有从头推，是跟着 B 站 shuhuai008 的白板推导看懂结论，再在这 8 个点上验的。谢谢大家。

【板书：原题下面写两行　① 无数条 → 最安全的一条　② 分不开 → 给违例定价】

# 追问和答法

## PPT 上老师自己写的三个问题

这三句分别写在 PPT 的“评分、边界与预测”“Soft margin 的优化目标”“Kernel：用相似度表达更丰富的边界”三页上，看起来是老师后加的提问，最可能被当场问到。

**decision score 有概率含义吗？跟概率什么关系？** 没有概率含义。我把线性模型在验证集上的分数分成四段，看真实异常的比例：f 小于负 1 的 9 个人里有 4 个异常，负 1 到 0 之间 25 个人里有 12 个，比例差不多，并没有越负越少。原因在 hinge，过了 1 就没有奖励，模型没有动力让分数的大小反映把握。逻辑回归的损失永远到不了零，它的分数才是对数几率。f 能用的是排序，所以 AUC 可以直接拿它算。真要概率，得另拿一份数据做 Platt scaling。

**软间隔这个目标有什么用？** 三个用处。一是把无解的硬约束变成能解的权衡，C 取很大就回到硬间隔。二是它就是“损失加正则”，hinge 换成交叉熵就是逻辑回归，C 相当于正则强度的倒数。三是它让一部分结论可以事先证明：C 增大，总 hinge 不增，w 的长度不减。

**Kernel 是什么？它跟对 x 做变换什么关系？** 核就是变换之后的内积。课上的二次核对应一个六维的变换，我拿两个点验过，直接算核和先变换再做内积都是 0.826。SVM 能用它，是因为 f 等于 α、y 和内积的加权和，数据只以内积出现。RBF 对应的变换是无限维的，所以只能算核，没法真去变换。

## 教案里列的追问，和我觉得会被问的

**为什么要除以权重长度？** w 和 b 同乘一个正数，边界和预测都不变，f 却跟着变。f 是函数间隔，除以 w 的长度才是几何间隔，不同的线才能比。

**判对了为什么还有损失？** y 乘 f 在 0 和 1 之间时，分对了但在带内，hinge 还是正的。SVM 罚的是“离边界不够远”，不只是“分错”。

**支持向量能不能当特征？是不是最典型的病人？** 都不是。支持向量是训练样本，是这组特征、这个 C、这些数据下贴着边界的点，换一组特征就换一批。

**博客说支持向量是“离超平面最近的点”，和老师的定义冲突吗？** 那是硬间隔的图。按老师的定义是对偶权重非零。我把 186 条训练集上的 α 读出来看过：89 个支持向量里只有 3 个的 α 在 0 和 C 之间，正好压在带上；另外 86 个的 α 等于 C，在带内或者分错了。

**间隔大到底保证了什么？** 保证已有的点不容易被小扰动翻过去。线性模型里，距离边界 d 的点翻转的概率是 Φ(−d/σ)。我按这个算出来的翻转率是 2.8%、5.4%、11.5%，实验是 3.0%、5.4%、12.1%。它不保证预测正确，也不保证新样本落在哪一侧。

**为什么线性 C 等于 0.01 最宽却最差？** 违例太便宜，w 被压到接近零，带宽是 2 除以 w 的长度所以很大，但 f 几乎是常数。宽是用“不区分”换来的。

**改变单位之后 gamma 还是同一种设置吗？** 数字相同，含义不同。gamma 作用在距离的平方上，一个输入乘 100，这一项就乘一万，同一个 gamma 的作用范围相对数据变得极小。标准化以后才是同一种设置。

**RBF 的虚线为什么不能和线性的间隔比宽窄？** RBF 的间隔在特征空间里。投回二维平面，f 等于正负 1 的等值线间距随位置变化，不是到边界的等距线。

**测试完如果想换核，需要什么？** 需要新的保留数据。这 62 条已经看过了，再用它选核，它就变成了第二个验证集。

**为什么倾向 linear 而不是验证分更高的 RBF？** 测试上两个只差一个病人；扰动实验里 RBF 的翻转率是 linear 的两倍；linear 的系数能解释。老师说不选冠军，所以我只说倾向。

**椎间盘突出的发现用了三分类标签，算不算偷看？** 三分类标签没有参与任何训练、选参和阈值，只用来解释错误是哪一类人，之后也没有再改模型。

**高维少样本和大样本为什么是不同的问题？** 高维少样本的问题是信号在不在、验证集稳不稳，是统计问题。大样本的问题是 n 乘 n 的核矩阵算不算得动，是计算问题。
